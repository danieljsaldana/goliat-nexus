# Créditos de la web del producto

La presentación toma como referencia la web de producto de `goliat-cloud-inventory`, propiedad de Daniel J. Saldaña. La estructura, el contenido y la identidad visual se han adaptado a Goliat - Nexus. El repositorio de referencia no se modifica.

Los diagramas utilizan el mismo runtime Archify 3.0.1 que incluye el repositorio de referencia, con sus adaptaciones locales, bajo licencia MIT. El código y la procedencia se conservan en `vendor/archify`, incluidos LICENSE, THIRD_PARTY_NOTICES.md y upstream.json. Se generan desde especificaciones propias de esta solución, sin consultar recursos Azure ni enviar datos a Archify.

Las fuentes DM Sans se sirven localmente, con la licencia incluida en `assets/DM-Sans-LICENSE.txt`. Los iconos de la interfaz usan Lucide 1.66.0, servido localmente mediante un sprite SVG con los iconos seleccionados. Se conservan sus licencias ISC/MIT en `assets/Lucide-LICENSE.txt`; la selección y la versión están en `content/icons.json`. El símbolo de Microsoft Azure y el logotipo de GitHub se reutilizan de la web de Goliat, a petición del propietario. Los nombres y las marcas Microsoft Azure, Terraform y otros productos pertenecen a sus titulares; no implican patrocinio ni certificación.

Los recursos y los entornos mostrados representan la versión 1.0.0 del producto. El renderer incluye tamaños de texto adaptados para mejorar la lectura de las vistas incrustadas. El entorno Prod de referencia requiere la aceptación en una suscripción real que se describe en la documentación.
